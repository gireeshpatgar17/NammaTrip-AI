# 3–5 minute voice-over demo script

**Target length:** about 4 minutes. Record the actual running app. Replace bracketed details only with verified facts.

### 0:00–0:25 — Opening
“Hi, we’re [team name], and this is NammaTrip AI, built for the Karnataka travel planner challenge. It helps a traveller turn their time, interests and budget into a practical Karnataka itinerary.”

### 0:25–0:55 — Set up the trip
Show **Plan a trip**. Choose Hampi, enter a starting city, select dates and a two-day duration, set a group budget and two travellers. Pick heritage, photography and food with a balanced pace. Mention that accommodation and dietary preferences are collected for planning context.

### 0:55–1:35 — Generate and explain
Click **Create my itinerary**. “The local planner is always available and uses the curated attraction data. With a Groq API key configured, optional AI can organize the same listed attractions; responses are checked against the catalogue. This run is using [state whether local or Groq AI, truthfully].” Open the itinerary tab and walk through the morning/afternoon/evening structure and visit durations.

### 1:35–2:05 — Explore the budget
Point to the group total, per-person estimate, remaining budget and category chart. “These are transparent planning allowances, not live prices or quotes. The totals recalculate from trip duration, group size, pace and travel mode.”

### 2:05–2:45 — Make the plan yours
Replace one attraction using the replacement control, reorder another activity, and remove an activity. Ask the trip assistant about the budget or a listed attraction. “The assistant uses curated facts and is clear that it cannot book services.”

### 2:45–3:15 — Explore and export
Show the destination explorer filter and one destination card. Return to the trip and demonstrate saving, then download the printable HTML or text plan. If time is short, show the buttons without opening the downloaded files.

### 3:15–3:50 — Close
“NammaTrip is designed to be useful without an AI key, transparent about estimates and grounded in a Karnataka destination catalogue. The current version focuses on one destination at a time; future work includes verified live sources, Kannada language support and multi-city routing. Thank you.”

### Recording checklist
- Use a clean browser window and readable zoom; close unrelated tabs and notifications.
- Use a real generated trip; do not imply live prices, route times, bookings or deployment unless verified.
- Keep voice-over clear and captions on if available. Target 3–5 minutes.
- Share the deployed URL on screen only after a successful deployment.
